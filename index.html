1. Constraint Satisfaction Engine

The autoScheduleAndBalance() algorithm scans for capacity deficits, then finds available off-duty staff whose assignment satisfies both SLA demands and rest-period constraints.

2. Automated Violation Resolution

The solver detects hazardous quick turnarounds (like Night → Morning) and excessive working streaks (>5 days), automatically inserting recovery rest windows and reallocating workload.

3. Client-Side Data Export

The exportToCSV() function converts the live schedule matrix into RFC-compliant CSV format and triggers a zero-dependency browser download for distribution.
